WRITING DESK — IMPORTANT
The Writing Desk saves drafts and entries in local browser storage on the device/browser where you use it. The "Add to local archive" action does NOT publish content to the public internet. It does not sync across devices. Export a JSON backup regularly. Do not treat this as a secure cloud account or online publishing CMS.

ONLINE WEBSITE
This is a static website package. To put the public pages online, you can upload the extracted files to a static host such as GitHub Pages or Netlify. The private Writing Desk remains local-only until a secure backend/CMS and authentication are separately configured. Do not put passwords or secret API keys in public files.
